# Skin-color Face Detection (C++ / OpenCV)

컴퓨터비전 Project #1 — 딥러닝·Haar 없이 피부색과 영상처리 기법만으로 웹캠에서 실시간 얼굴을 검출한다.

## 알고리즘

```
웹캠 프레임 → YCbCr 변환 + 피부색 이진화 → 모폴로지(열림/팽창/닫힘)
→ 연결요소 라벨링 → 기하학적 필터(크기·종횡비) → 눈·입 구멍 검사 → 이마~턱 경계상자
```

| 단계 | 내용 |
|---|---|
| 피부색 마스크 | YCbCr에서 Y 40~230, Cr 135-170, Cb 85-120이면 255 |
| 모폴로지 | 3×3 타원 커널로 열림 → 팽창 → 닫힘 (눈·입 구멍은 남김) |
| 라벨링 | `connectedComponentsWithStats` (8방향) |
| 기하학적 필터 | 화면의 0.3%-40% 크기, 가로·세로 30px 이상, 종횡비 0.4-2.0 |
| 얼굴 확정 | `findContours(RETR_CCOMP)`로 내부 구멍 2개 이상인 덩어리만 얼굴 (손·목은 구멍이 없음) |
| 박스 | 가장 아래 구멍(입) 아래 6%를 턱으로 보고 이마~턱만 표시 |

## 실행

OpenCV 4.x, C++. Visual Studio 프로젝트에 `face_detection.cpp`를 넣고 실행하면 기본 웹캠(0번)이 켜진다. `ESC`로 종료.

```bash
g++ -O2 face_detection.cpp -o face_detection `pkg-config --cflags --libs opencv4`
```

## 한계

- 옆얼굴처럼 눈·입 구멍이 안 보이면 검출이 불안정하다.
- 나무색·살구색 배경이나 사진 속 얼굴을 오검출할 수 있다.
- 극단적인 조명에서는 피부색 범위를 벗어난다.
